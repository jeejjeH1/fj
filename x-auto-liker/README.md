# X Auto Liker

اکستنشن کروم که لینک توییت‌ها (حداکثر ۳۰ تا) را نوبت‌به‌نوبت در یک تب باز می‌کند، توییت اصلی را لایک می‌کند و بعد از فاصله‌ی زمانی‌ای که خودتان تنظیم می‌کنید سراغ لینک بعدی می‌رود تا لیست تمام شود.

## نصب

1. این پوشه (`x-auto-liker`) را روی کامپیوترتان داشته باشید.
2. در کروم بروید به `chrome://extensions`.
3. بالا سمت راست **Developer mode** را روشن کنید.
4. روی **Load unpacked** بزنید و پوشه‌ی `x-auto-liker` را انتخاب کنید.
5. آیکون اکستنشن را از منوی پازل 🧩 پین کنید.

(روی Edge و Brave هم همین‌طور کار می‌کند.)

## استفاده

1. اول در همان مرورگر وارد حساب X خودتان شوید.
2. روی آیکون اکستنشن بزنید و لینک‌ها را بچسبانید — هر خط یکی (لینک‌های `x.com` و `twitter.com` هر دو قبول است، تکراری‌ها حذف می‌شوند).
3. **فاصله بین هر لایک**: چند ثانیه بعد از هر لایک صبر کند.
4. **تصادفی اضافه تا**: یک مقدار تصادفی بین ۰ تا این عدد به فاصله اضافه می‌شود تا رفتار طبیعی‌تر باشد (اگر نمی‌خواهید، ۰ بگذارید).
5. **شروع** را بزنید. می‌توانید پنجره‌ی اکستنشن را ببندید؛ کار در پس‌زمینه ادامه پیدا می‌کند و هر وقت دوباره بازش کنید وضعیت هر لینک را می‌بینید.
6. با **توقف** هر لحظه می‌توانید متوقفش کنید.

وضعیت هر لینک:
- ✓ لایک شد
- • از قبل لایک بود (دوباره کلیک نمی‌کند تا آنلایک نشود)
- ✗ خطا (مثلاً توییت پاک شده یا پیدا نشد)

## نکته‌ها

- فقط توییت اصلی همان لینک لایک می‌شود، نه ریپلای‌ها یا توییت والد.
- فاصله‌ی خیلی کم (مثلاً زیر ۵ ثانیه) ممکن است باعث محدودیت موقت حساب از طرف X شود؛ ۱۰ ثانیه به بالا امن‌تر است.
- اگر وارد حساب نشده باشید، اکستنشن متوقف می‌شود و پیام می‌دهد.
